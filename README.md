# 📚 BookSmart – Library Management System

BookSmart is a **web-based Library Management System** developed using **Oracle APEX**, **SQL**, and **PL/SQL**.  
The system automates core library operations such as book management, borrowing and returns, user management, and fine tracking.

This project was developed as part of an academic **Software Development** course and demonstrates real-world database-driven application design.

---

## ✨ Key Features

- Role-based authentication (Librarian & Users)
- Book catalog management
- Book borrowing and return processing
- Automatic fine calculation (late, lost, or damaged books)
- Fine payment tracking
- User dashboards (borrowing history & fines)
- Administrative reports and dashboards
- Secure data handling using database constraints and triggers

---

## 🛠️ Technologies Used
